# veterinary-clinic-ai dependencies
#
# NOTE on heavy deps: `torch` and `transformers` are ONLY used by the
# optional computer-vision triage step (app/services/cv_triage.py), which
# does zero-shot image classification with a pretrained CLIP model. They
# are large downloads (torch especially). The service is designed to
# degrade gracefully without them:
#   - If ENABLE_CV=false, they are never imported/loaded at all.
#   - If they ARE enabled but not installed (or the model fails to
#     download at runtime), cv_triage.classify_photos() catches the
#     ImportError/exception, logs a warning, and returns None -- the
#     triage endpoint still returns a valid NLP-only result
#     (cv_confidence: null) instead of crashing.
# For a lightweight/NLP-only dev setup you may comment torch/transformers
# out and run with ENABLE_CV=false.
